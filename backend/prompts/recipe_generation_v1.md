# recipe_generation_v1

> **注意**: このファイルはドキュメント用。実際のプロンプトは `meal_agent.py` の
> `_build_recipe_prompt` / `_call_recipe_llm` に実装されている。

---

## Human メッセージ

```
料理名: {concept}
利用可能な食材: {estimated_ingredients}

家庭で作りやすい2〜4人前のレシピをJSONで出力してください。
instructions_md は必ず以下のフォーマットに従ってください:

## 材料（2〜4人前）
- 食材名: 分量・単位

## 下準備（省略可）
- 下準備の手順

## 手順
1. 手順の説明

## Tips（省略可）
- コツや補足

出力例:
{"name":"豚の生姜焼き","instructions_md":"## 材料（2〜4人前）\n- 豚ロース薄切り: 300g\n...","cook_time_min":20,"cost_estimate":"600円程度","ingredients":[...]}
```

## System メッセージ

```
あなたはプロの料理家です。家庭で実践できる詳細なレシピをJSON形式で出力してください。
instructions_md のセクション見出しは必ず ## を使い、
材料は '- 食材名: 分量・単位' 形式、手順は '1. ' から始まる番号リスト形式で統一してください。
説明やコードブロックは使わず、JSONのみ出力してください。
```

## instructions_md フォーマット規定

| セクション | 必須 | 形式 |
|-----------|------|------|
| `## 材料（2〜4人前）` | ✅ | `- 食材名: 分量・単位` |
| `## 下準備` | 省略可 | `- 手順` |
| `## 手順` | ✅ | `1. 手順` の番号リスト |
| `## Tips` | 省略可 | `- コツ・補足` |

## モデル設定

- model: `claude-sonnet-4-6`
- temperature: 0.5
- max_tokens: 4096
